# فروشگاه هوم‌زی (نسخه اولیه)

## فایل‌ها
- `index.html`: ساختار صفحه
- `style.css`: ظاهر، رنگ‌ها و واکنش‌گرایی موبایل
- `script.js`: محصولات نمونه، دسته‌بندی، جستجو و سبد خرید نمایشی

## انتشار روی GitHub Pages
1. یک مخزن جدید در GitHub بسازید؛ مثلاً `homezee-store`.
2. هر سه فایل `index.html`، `style.css` و `script.js` را در ریشه مخزن بارگذاری کنید.
3. وارد Settings > Pages شوید.
4. در بخش Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
5. Branch را روی `main` و پوشه را روی `/ (root)` قرار دهید و Save را بزنید.
6. پس از چند دقیقه، نشانی عمومی سایت در همان صفحه نمایش داده می‌شود.

## ویرایش محصولات
در ابتدای فایل `script.js` آرایه `products` را پیدا کنید. برای هر محصول مقدارهای `name`، `category`، `price`، `emoji` و `tone` را تغییر دهید.
قیمت‌ها در این نسخه نمونه هستند.

## نکته مهم
این نسخه یک ویترین فروشگاهی فرانت‌اند است. سبد خرید فقط در مرورگر و تا زمان تازه‌سازی صفحه نگهداری می‌شود و پرداخت آنلاین، ثبت سفارش روی سرور، پنل مدیریت و ذخیره دائمی اطلاعات ندارد. برای این امکانات به بک‌اند یا سرویس جداگانه نیاز است.
